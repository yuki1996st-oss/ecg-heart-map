# 嚥下評価アプリ（院内用）

急性期病棟のベッドサイドで、嚥下スクリーニングの記録・判定の整理・カルテ用文章の作成までを
1つの画面で行うための、ブラウザだけで動くアプリです。

## できること

- **入力**：基本情報／実施前の安全チェック／問診（EAT-10・聖隷式嚥下質問紙）／口腔（OHAT-J・オーラルディアドコキネシス）／
  ベッドサイド・スクリーニング（RSST・MWST・フードテスト・30mL水飲みテスト・咳テスト・頸部聴診）／
  重症度（DSS・藤島Gr・FILS・FOIS）／食形態（学会分類2021）・代償法・訓練メニュー
- **自動判定**：各テストの基準に照らした判定表示と、リスクの目安・対応案（あくまで参考）
- **カルテ用テキスト**：入力内容から文章を自動生成し、ワンタップでコピー
- **記録**：患者ID（またはイニシャル）ごとに保存・呼び出し。CSV／JSONで書き出し
- **印刷・PDF保存**、**オフライン動作**、iPhone・iPad・Macに対応

## 使い方

1. `index.html` をブラウザで開きます（GitHub Pages で公開した場合は `.../dysphagia/` を開きます）。
2. 上から順に入力すると、画面下の「判定・サマリー」が自動で更新されます。
3. 「カルテ用テキストをコピー」で電子カルテに貼り付け、「この評価を保存」で端末に記録が残ります。
4. iPhoneはSafariの共有ボタン →「ホーム画面に追加」で、アプリのように使えます。

## 個人情報について

- 患者氏名は入力しない設計です（患者ID・イニシャルのみ）。
- 入力内容は**インターネットに送信されず**、使っている端末のブラウザ内（localStorage）にだけ保存されます。
- 共用端末で使った場合は、「記録一覧」→「保存データを全部消す」で削除してください。
- 実際の運用は、所属施設の個人情報の取り扱いルールに従ってください。

## 注意

このアプリは記録・整理を助けるツールです。表示される判定や推奨は一般的な目安であり、
最終的な判断は担当医・評価者が患者さんの全身状態を含めて行ってください。

## ファイルの役割

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `data.js` | **評価項目・選択肢・早見表の文章（内容を直すのはここ）** |
| `app.js` | 画面の組み立て・自動判定・保存の仕組み |
| `style.css` | 見た目 |
| `sw.js` / `manifest.webmanifest` | オフライン動作・ホーム画面追加のための設定 |

評価項目や文章を追加・修正したいときは `data.js` の中の「" "で囲まれた日本語」を書き換えてください。
`sw.js` の `CACHE_NAME`（`dysphagia-v1`）の数字を1つ増やすと、更新した内容が確実に反映されます。

## 参考にした評価指標

RSST（反復唾液嚥下テスト）、改訂水飲みテスト（MWST）、フードテスト、30mL水飲みテスト（窪田法）、
EAT-10、聖隷式嚥下質問紙、OHAT-J、摂食嚥下障害臨床的重症度分類（DSS）、
藤島の摂食嚥下能力グレード、摂食状況のレベル（FILS）、FOIS、
日本摂食嚥下リハビリテーション学会 嚥下調整食分類2021。
