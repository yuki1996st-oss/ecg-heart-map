# 米国株 承認制ツール（moomoo OpenAPI）

MacBook で動かす、**自分で最終判断する**運用支援セットです。

## この構成

| 項目 | 決めたこと |
|---|---|
| 対象 | **米国株**（1株から買えるので10万円でも分散できる） |
| 任せ方 | **承認制**：プログラムはサインを知らせるだけ。発注は自分で |
| ペース | **中期**：数週間〜数ヶ月。移動平均クロス |
| 予算 | 10万円 / 1銘柄あたり上限2万円 / 最大5銘柄 / 損切り -8% |

> ### 自動発注はしません
> このフォルダで**注文を出せるスクリプトは `2_paper_order.py` ただ1つ**で、
> それは模擬取引（仮想のお金）でしか動きません。起動時に検査し、
> 本番設定になっていたらその場で止まります。
>
> `6_signal_check.py` を含む他のスクリプトは**すべて読むだけ**です。
> サインを知らせることはあっても、注文は一切出しません。

## ファイルの役割

| ファイル | 何をする | お金は動く？ |
|---|---|---|
| `1_check_connection.py` | 接続できるか確認 | 動かない |
| `2_paper_order.py` | 模擬注文を1回出す | 仮想のお金のみ |
| `3_fetch_history.py` | 過去データを CSV に保存 | 動かない |
| `4_backtest.py` | 過去データで検証 | 動かない |
| `5_export_dashboard.py` | 口座状況を読み出す | 動かない |
| **`6_signal_check.py`** | **売買サインを探して通知** | **動かない（注文しない）** |
| `dashboard/index.html` | 結果を図で見る | 動かない |

## 準備1：moomoo 側

1. moomoo証券アプリで **模擬取引（ペーパートレード）** を一度開き、模擬口座を作る
2. [moomoo OpenAPI のページ](https://www.moomoo.com/ja/OpenAPI)から **OpenD**（Mac版）をダウンロード
3. OpenD を起動してログイン。「接続済み」と出ればOK
   - OpenD は「MacBook と moomoo をつなぐ中継ソフト」です
   - **これが起動していないと何も動きません**（トラブルの9割がこれ）
   - 常時起動するので、ログイン時に自動で立ち上がる設定にしておくと楽です

`cd` と `source venv/bin/activate` から。

## 使う順番

### 1. つながるか確認

```bash
python3 1_check_connection.py
```

### 2. 模擬注文を1回だけ試す（仮想のお金）

```bash
python3 2_paper_order.py
```

`yes` と入力するまで発注しません。出した注文は moomoo アプリの「模擬取引」から取り消せます。

### 3. 過去データを集めて、ルールを検証する

```bash
python3 3_fetch_history.py      # ウォッチリスト全銘柄の日足を保存
python3 4_backtest.py --all     # 銘柄ごとに横並びで比較
```

`--all` は、どの銘柄でこのルールが機能していたかを一覧にします。
グラフで詳しく見たい銘柄は `python3 4_backtest.py data/US_SPLG.csv` のように指定します。

### 4. 売買サインを確認する（毎日の作業）

```bash
python3 6_signal_check.py
```

- ウォッチリストを調べて、買い候補・売り候補・損切り検討を出します
- サインがあれば **Mac の通知**が出ます
- **注文は出しません。** moomoo アプリで自分で確認してから発注してください

### 5. ダッシュボードで見る

```bash
python3 5_export_dashboard.py
```

そのあと `dashboard/index.html` を**ダブルクリック**。
今日のサイン・口座の状況・バックテスト結果がまとめて見られます。

## 毎朝の自動チェック（launchd）

MacBook を常時起動しておくなら、毎朝7:30に自動でサインを確認して通知を出せます。
米国市場は日本時間の朝6時頃に閉まるので、その直後に見る形です。

```bash
# 1. 設定ファイルに、このフォルダの実際のパスを埋め込む
TRADING_DIR="$(pwd)"
sed "s|__TRADING_DIR__|$TRADING_DIR|g" com.local.moomoo-signal.plist \
  > ~/Library/LaunchAgents/com.local.moomoo-signal.plist

# 2. 登録する
launchctl load ~/Library/LaunchAgents/com.local.moomoo-signal.plist

# 3. 動くか今すぐ試す
launchctl start com.local.moomoo-signal
cat logs/signal_check.log
```

やめたいとき：

```bash
launchctl unload ~/Library/LaunchAgents/com.local.moomoo-signal.plist
```

時刻を変えたいときは plist の `Hour` / `Minute` を直して、unload → load し直します。

## 10万円で米国株をやるときの注意

### 1株の値段が壁になります

1銘柄あたり2万円の枠なので、**1株 約130ドルを超える銘柄は買えません**。
VOO（約600ドル＝9万円）や MSFT（約400ドル＝6万円）は、サインが出ても見送りになります。
`6_signal_check.py` が「予算の枠を超えている銘柄」を毎回知らせるので、
出てきたら `config.py` の `WATCHLIST` を入れ替えてください。

初期設定の銘柄は「1株が安く、取引量が多い」という基準で並べただけで、
**買うべき銘柄という意味ではありません。** 納得できるものに入れ替えてください。

### 為替

米ドル建てなので、株価が動かなくても円換算の損益は動きます。
ダッシュボードの円表示は `config.py` の `USDJPY_ASSUMED`（初期値150円）を
使った**概算**です。正確な数字は moomoo アプリで確認してください。

### 税金

**特定口座（源泉徴収あり）**にしておくと、証券会社が計算して納税まで
やってくれるので、確定申告が原則不要になります。本業がある方には
これが一番楽です。口座の種類は moomoo アプリで確認できます。

### 取引時間

日本時間の 23:30〜翌6:00 頃（夏時間は1時間前倒し）。
日中の勤務には影響しませんが、逆に言うと**寝ている間に動きます**。
だから承認制（朝に確認してから発注）が噛み合っています。

## 運用ルール（最初に決めたこと）

`config.py` で変えられます。

| 設定 | 初期値 | 意味 |
|---|---|---|
| `TOTAL_BUDGET_JPY` | 100,000 | 全体の予算 |
| `MAX_POSITIONS` | 5 | 同時に持つ銘柄数の上限 |
| `BUDGET_PER_STOCK_JPY` | 20,000 | 1銘柄あたりの上限（自動計算） |
| `STOP_LOSS_PCT` | 8.0 | この%下がったら損切りを知らせる |
| `SMA_SHORT` / `SMA_LONG` | 25 / 75 | 移動平均の日数 |

**損切りルールを守ることが、この仕組みで一番大事な部分です。**
「もう少し待てば戻るかも」で持ち続けると、-8% のルールは意味を失います。
ルールを破りたくなったら、それはルールを変えるべきというサインかもしれないので、
そのときは一度相談してください。

## バックテストの読み方で気をつけること

- **過去に上手くいった ≠ これから上手くいく。** ここが最大の落とし穴です。
  パラメータをいじって成績が良くなるのは当たり前で（過剰最適化）、
  「過去の答えを覚えただけ」のことが多いです
- **最大ドローダウン**を先に見てください。「途中でどれだけ含み損に耐えるか」です。
  -30% を数字で見るのと、10万円が7万円になった画面を実際に見るのは、全く違います
- 計算には**税金・スリッページ（思った値段で買えないこと）・為替**が
  入っていません。実際の成績はこれより悪くなります

## 本番口座に切り替えるとき

`config.py` の `TRD_ENV` を `TrdEnv.REAL` に変えると、
`1_check_connection.py` `5_export_dashboard.py` `6_signal_check.py` が
本番口座を**見る**ようになります。これらは読むだけなので安全です。
実行すると画面に「本番口座の情報を見ています」と警告が出ます。

`2_paper_order.py` は模擬専用なので、本番設定では起動した瞬間に止まります。
**発注は moomoo アプリから手で行ってください。** それが承認制です。

模擬で2〜3ヶ月動かして、サインの出方と自分の反応が分かってから
切り替えることをおすすめします。
