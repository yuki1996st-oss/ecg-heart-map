# 模擬取引ツール一式（moomoo OpenAPI）

MacBook で動かす、**仮想のお金だけ**の練習セットです。

| やること | 使うファイル | お金は動く？ |
|---|---|---|
| ① 接続できるか確認 | `1_check_connection.py` | 動かない（見るだけ） |
| ① 模擬注文を出してみる | `2_paper_order.py` | **仮想のお金**のみ |
| ② 過去データを集める | `3_fetch_history.py` | 動かない |
| ② 過去データで検証する | `4_backtest.py` | 動かない（計算だけ） |
| ③ 口座の状況を図で見る | `5_export_dashboard.py` → `dashboard/index.html` | 動かない（読むだけ） |

> **安全装置について**
> `config.py` の `TRD_ENV` は `SIMULATE`（模擬）に固定してあります。
> ここを `REAL` に書き換えない限り、本物のお金は1円も動きません。
> スクリプトは起動時に必ずこの値を確認し、`SIMULATE` 以外なら即座に止まります。

---

## 準備1：moomoo 側

1. moomoo証券アプリで **模擬取引（ペーパートレード）** を一度開き、模擬口座を作る
2. [moomoo OpenAPI のページ](https://www.moomoo.com/ja/OpenAPI)から **OpenD**（Mac版）をダウンロード
3. OpenD を起動し、moomoo のアカウントでログイン
   - OpenD は「MacBook と moomoo のサーバーをつなぐ中継ソフト」です
   - **これが起動していないと、以下のスクリプトは何も動きません**
   - 画面に「接続済み」と出ればOK。起動したまま放置しておきます

---

## 準備2：MacBook 側（ターミナル）

ターミナルの開き方：`command + スペース` → `ターミナル` と入力 → Enter

### Python があるか確認

```bash
python3 --version
```

`Python 3.x.x` と出ればOK。「コマンドが見つかりません」と出たら、
表示される案内にしたがって開発者ツールを入れるか、
[python.org](https://www.python.org/downloads/macos/) から入れてください。

### このフォルダに移動して、必要な部品を入れる

```bash
cd ~/Desktop/ecg-heart-map/trading      # ← 置いた場所に合わせて変えてください

python3 -m venv venv                    # 専用の作業部屋を作る（初回だけ）
source venv/bin/activate                # 作業部屋に入る（毎回）
pip install -r requirements.txt         # 部品を入れる（初回だけ）
```

`source venv/bin/activate` を実行すると、行の先頭に `(venv)` と付きます。
**これが付いている状態**で以下を実行してください。
ターミナルを閉じたら、次回はまた `cd` と `source venv/bin/activate` から。

## ① 模擬取引を動かす

### 1-a. つながるか確認（注文は出しません）

```bash
python3 1_check_connection.py
```

株価・模擬口座の残高が表示されれば成功です。
失敗したら、まず **OpenD が起動しているか**を疑ってください。9割これです。

### 1-b. 模擬注文を1回出してみる

```bash
python3 2_paper_order.py
```

現在値より5%安い指値で買い注文を出します（すぐには約定しない価格です）。
`yes` と入力しないと発注しません。出した注文は moomoo アプリの
「模擬取引」画面から取り消せます。

扱う銘柄を変えたいときは `config.py` の `TEST_CODE` を書き換えます
（日本株は `"JP.7203"`、米国株は `"US.AAPL"` のような書き方）。

---

## ② バックテスト（過去データでの検証）

### サンプルですぐ試す

口座も OpenD も無くても動きます。

```bash
python3 4_backtest.py
```

### 実データで試す

```bash
python3 3_fetch_history.py       # 過去データを data/ に保存
python3 4_backtest.py data/JP_7203.csv
```

戦略は「**短期の移動平均が長期を上抜いたら買い、下抜いたら手仕舞い**」という、
一番シンプルなものです。日数や元手は `config.py` の
`SMA_SHORT` / `SMA_LONG` / `INITIAL_CASH` で変えられます。

### 読み方で気をつけること

- **過去に上手くいった ≠ これから上手くいく。** ここが一番の落とし穴です。
  パラメータをいじって成績が良くなるのは当たり前で（過剰最適化といいます）、
  それは「過去の答えを覚えた」だけのことが多いです。
- **最大ドローダウン**は「途中でどれだけ含み損に耐えることになるか」。
  総リターンより、こちらを先に見てください。-30% を実際に耐えられるかどうかは、
  数字で見るのと実際に体験するのとで全く違います。
- この計算には **税金・株数の単位・スリッページ**（思った値段で買えないこと）
  が入っていません。実際の成績はこれより悪くなります。

## ③ ダッシュボードで見る

```bash
python3 5_export_dashboard.py
```

模擬口座の残高と保有銘柄を読み取って、`dashboard/portfolio_data.js` に書き出します。
**読むだけのスクリプト**で、発注の機能は一行も入っていません。

そのあと `dashboard/index.html` を **ダブルクリック**すると Safari で開きます。

- 模擬口座の総資産・保有銘柄
- バックテストの成績と資産推移のグラフ
- 売買の記録

データはこの MacBook の中のファイルを読んでいるだけで、どこにも送信されません。
右上のボタンで明るい／暗い表示を切り替えられます。

## ここから先（本番口座）に進む前に

このセットには、わざと本番用の仕組みを入れていません。理由は3つです。

1. **自動売買は「止まる」のではなく「動きながら損を出す」**ことがあります。
   夜中に暴走していても気づけません。
2. **MacBook を24時間つけっぱなしにする必要があります。**
   スリープすれば止まりますし、途中で止まった時に
   「持ったまま放置」になるのが一番危険です。
3. **AI（Claude）は相場を予測できません。**
   判断をさせるのではなく、人間が決めたルールをプログラムに淡々と
   実行させる形が現実的です。

模擬取引で数か月ぶん動かして、想定外の動きが出尽くしてから考えるのをおすすめします。
